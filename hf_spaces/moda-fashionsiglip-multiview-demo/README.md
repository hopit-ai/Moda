# MODA FashionSigLIP Multi-View Search

Upload a small fashion catalog, build the three-route index, and search it with
natural-language queries.

This Space demonstrates the exact zero-additional-parameter architecture from
[`HopitAI/moda-fashionsiglip-multiview-203m`](https://huggingface.co/HopitAI/moda-fashionsiglip-multiview-203m).

The base neural checkpoint is the unchanged
[`Marqo/marqo-fashionSigLIP`](https://huggingface.co/Marqo/marqo-fashionSigLIP).
Uploaded files are used only for the active Space session.
